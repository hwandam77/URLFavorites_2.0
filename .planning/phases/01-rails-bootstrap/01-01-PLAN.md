    1. `config/database.yml`을 아래와 같이 작성하여 main DB와 queue DB를 분리한다:

    ```yaml
    default: &default
      adapter: sqlite3
      pool: <%= ENV.fetch("RAILS_MAX_THREADS") { 5 } %>
      timeout: 5000

    development:
      <<: *default
      database: storage/development.sqlite3

    test:
      <<: *default
      database: storage/test.sqlite3

    production:
      <<: *default
      database: storage/production.sqlite3

    queue:
      <<: *default
      database: storage/queue.sqlite3

    cache:
      <<: *default
      database: storage/cache.sqlite3
    ```

    2. `config/initializers/solid_queue.rb`를 생성한다:

    ```ruby
    # AI Job 동시성 제한 — llama-server OOM 방지
    # AnalyzeWebpageJob, AnalyzeYoutubeJob 최대 동시 실행 수: 2
    Rails.application.config.solid_queue.connects_to = { database: { writing: :queue } }

    SolidQueue.on_start do
      SolidQueue::Worker.default_concurrency = 2
    end
    ```

    **주의:** SolidQueue API가 위 방식을 지원하지 않으면, 대신 `config/queue.yml` 또는 `config/solid_queue.yml`에 아래 내용을 추가한다:

    ```yaml
    default: &default
      workers:
        - queues: [ai_analysis]
          threads: 2
        - queues: [default]
          threads: 5
    ```

    그리고 `config/initializers/solid_queue.rb`에는 DB 연결만 남긴다:
    ```ruby
    # Solid Queue — queue DB 연결
    # AI Job 동시성(max 2)은 config/queue.yml workers 섹션에서 설정
    Rails.application.config.solid_queue.connects_to = { database: { writing: :queue } }
    ```

    3. `.gitignore`에 아래 항목이 포함되어 있는지 확인하고, 없으면 추가한다:
    ```

    /storage/*.sqlite3-wal
    .env
    .env.*

    /config/master.key
    /config/credentials/*.key
    ```

    4. `config/environments/production.rb`에 `LLAMA_SERVER_URL` 필수 확인 로직을 추가한다:
    ```ruby
    # LLAMA_SERVER_URL이 없으면 시작 거부 (AI 분석 필수 의존성)
    Rails.application.config.after_initialize do
      if ENV["LLAMA_SERVER_URL"].blank?
        raise "LLAMA_SERVER_URL environment variable is required"
      end
    end
    ```
