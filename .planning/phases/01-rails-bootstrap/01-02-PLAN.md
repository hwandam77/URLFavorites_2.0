    # URLFavorites 2.0

    개인용 URL 북마크 관리자. URL(웹페이지/YouTube)을 저장하면 로컬 LLM이 자동으로 요약, 태그, 핵심 인사이트를 추출한다.

    - **서비스 주소**: https://urlf2.hwandam.kr
    - **스택**: Rails 8.1.x, Ruby 3.4.9, SQLite3, Solid Queue, Hotwire, Tailwind CSS
    - **AI**: Qwen3-30B-A3B-Instruct (llama-server, WireGuard VPN 경유)

    ---

    ## 로컬 실행

    ### 사전 요구사항

    - Ruby 3.4.9 (`rbenv` 또는 `rvm` 권장)
    - Bundler (`gem install bundler`)
    - yt-dlp (`brew install yt-dlp` 또는 `pip install yt-dlp`)
    - WireGuard VPN 연결 (llama-server 접근용)

    ### 설정

    ```bash
    # 1. 의존성 설치
    bundle install

    # 2. 환경 변수 설정 (.env 파일 생성 또는 직접 export)
    export LLAMA_SERVER_URL=http://<beacon-wg-ip>:<port>

    # 3. DB 생성 및 마이그레이션
    bin/rails db:create db:migrate

    # 4. 서버 실행
    bin/rails server
    ```

    ### Solid Queue (백그라운드 Job) 실행

    ```bash
    bin/jobs
    ```

    또는 별도 터미널에서:

    ```bash
    bin/rails solid_queue:start
    ```

    ---

    ## 환경 변수

    | 변수명 | 필수 여부 | 설명 |
    |--------|----------|------|
    | `LLAMA_SERVER_URL` | **필수** | llama-server HTTP 엔드포인트 (예: `http://10.10.0.x:8080`) |
    | `SECRET_KEY_BASE` | 프로덕션 필수 | Rails 세션 암호화 키 (`rails secret`으로 생성) |
    | `RAILS_MASTER_KEY` | 프로덕션 필수 | credentials 복호화 키 |
    | `RAILS_ENV` | 선택 | `development` (기본값), `production` |

    > `LLAMA_SERVER_URL`이 없으면 프로덕션 환경에서 앱이 시작되지 않는다.

    ---

    ## 초기 배포 (최초 1회)

    ### 1. 서버 사전 요구사항 확인

    - [ ] Ruby 3.4.9 설치됨 (`ruby --version`)
    - [ ] Bundler 설치됨 (`bundle --version`)
    - [ ] yt-dlp 설치됨 (`yt-dlp --version`) — YouTube 추출 필수
    - [ ] SQLite3 설치됨 (`sqlite3 --version`)

    서버의 환경 변수 파일 또는 systemd service 파일에 아래 변수를 설정한다:

    - [ ] `LLAMA_SERVER_URL=http://<beacon-wg-ip>:<port>` — **필수**
    - [ ] `SECRET_KEY_BASE=<rails secret 출력값>` — **필수**
    - [ ] `RAILS_MASTER_KEY=<config/master.key 내용>` — **필수**
    - [ ] `RAILS_ENV=production`

    ### 3. 배포 실행

    ```bash
    deploy urlfavorites
    ```

    이 명령은 rsync로 코드를 전송하고 서비스를 재시작한다.

    ### 4. 초기 DB 마이그레이션

    ```bash
    # 서버에서 실행

    ```
