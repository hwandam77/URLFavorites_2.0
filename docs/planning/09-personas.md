# 09 — 페르소나

## 사용자 프로필

1인 사용자 전용 시스템이므로 별도 시장 세분화 없이
실제 사용 패턴과 시나리오를 기반으로 작성.

---

## 유일한 사용자: 개발자-본인

| 항목 | 내용 |
|------|------|
| 직종 | 소프트웨어 개발자 |
| 기술 수준 | 고급 (시스템 직접 구축) |
| 주요 관심사 | AI, 개발 기술, 아키텍처, 도구 |
| 저장 콘텐츠 | 기술 블로그, YouTube 강의, GitHub 저장소 링크, 논문 요약 |
| 사용 기기 | 맥북 (메인), iPhone (이동 중) |
| 사용 패턴 | 하루 수회 저장, 주 1-2회 집중 탐색 |

---

## 사용 시나리오 3가지

---

### 시나리오 1: 이동 중 발견 저장

**상황**
출퇴근 지하철에서 스마트폰으로 Tech 뉴스를 읽다가 흥미로운 AI 논문 요약 블로그 글을 발견.

**행동 흐름**
1. Safari에서 기사 읽다가 "나중에 자세히 읽어야겠다" 생각
2. 공유 버튼 탭 → 공유 시트에서 "urlf2" 선택
3. 저장 확인 화면 잠깐 보고 Safari로 돌아옴
4. (백그라운드) AI가 자동으로 요약, 태그 생성
5. 저녁에 맥북에서 urlf2 열어서 "오늘 저장한 것" 확인

**핵심 요구사항**
- 저장 마찰 최소화 (2-3탭 이내)
- 모바일 공유 시트 등록 (PWA share_target)
- 저장 확인 후 자동 닫힘 (앱 복귀 불필요)

---

### 시나리오 2: 데스크탑 리서치 중 연속 저장

**상황**
새 프로젝트 기술 스택을 리서치하는 중 관련 블로그, 공식 문서, YouTube 영상 여러 개를 연속으로 저장.

**행동 흐름**
1. urlf2 홈을 별도 탭에 열어둠
2. 각 URL을 통합 입력바에 붙여넣기 → Enter (반복)
3. 카드가 빠르게 상단에 추가됨 (pending 상태)
4. 리서치 계속 진행 (분석 기다리지 않음)
5. 30분 후 urlf2 탭 확인 → 대부분 done 상태, AI 태그 붙어있음
6. "rails" 태그로 필터 → 관련 항목만 보기
7. 특정 YouTube 영상 카드 클릭 → AI 요약으로 핵심 내용 빠르게 파악

**핵심 요구사항**
- 연속 저장 시 입력바 즉시 초기화 (저장 후 포커스 유지)
- 비동기 분석 (저장 즉시 UI 응답, 분석은 백그라운드)
- Turbo Stream으로 분석 완료 시 자동 업데이트 (새로고침 불필요)
- 태그 필터로 빠른 그룹핑

---

### 시나리오 3: 나중에 "그거 어디있더라" 검색

**상황**
2주 전에 읽었던 "SQLite WAL 모드 성능 비교" 글이 필요한 상황. 제목이나 URL이 정확히 기억나지 않음.

**행동 흐름**
1. urlf2 홈 열기
2. 통합 입력바에 "sqlite wal" 입력 → Enter
3. FTS5 검색으로 결과 즉시 표시
4. 결과 중 해당 글 카드 발견 → 클릭
5. 상세 페이지에서 AI 핵심포인트 보며 내용 빠르게 리마인드
6. 원본 링크로 이동

**또는 (태그 기억하는 경우)**
1. "sqlite" 태그 칩 클릭 → 태그 필터
2. 목록에서 해당 글 찾음

**핵심 요구사항**
- FTS5 전문 검색: title, summary, tags, note 통합
- 검색 결과 빠른 표시 (Turbo Frame)
- AI 요약이 검색 결과로 연결되어야 함 (원문 안 읽어도 됨)
- 핵심포인트로 빠른 내용 파악

## 사용자 불편 지점 (Pain Points)

| 불편 | 현재 상황 | urlf2의 해결 |
|------|----------|-------------|
| 저장이 귀찮음 | 제목/태그 입력 필요 | URL만 붙여넣기 |
| "어디 저장했더라" | 브라우저 북마크 정리 어려움 | FTS5 + AI 태그 검색 |
| 이동 중 발견 저장 불편 | 모바일 브라우저 북마크는 데스크탑에서 보기 어려움 | PWA 공유 시트 |
| YouTube 내용 파악에 시간 소요 | 30분짜리 영상 직접 봐야 함 | AI 자막 분석 → 핵심포인트 |
| 저장한 걸 또 저장 | 중복 확인 어려움 | 중복 URL 자동 감지 |

## 비사용 케이스 (Out of Scope)

- 다른 사람과 공유 기능
- 팀 협업
- 공개 아카이브
- 소셜 기능 (좋아요, 댓글)
- 이메일 알림

위 기능은 1인 사용자 전제와 운영 단순화 제약으로 제외.
