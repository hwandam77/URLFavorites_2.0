# 04 — 화면 설계

## 화면 목록

| ID | 화면명 | 라우트 | 설명 |
|----|--------|--------|------|
| S01 | 홈 (아카이브) | `GET /` 또는 `GET /favorites` | 메인 화면, 통합 입력바 + 카드 목록 |
| S02 | 상세 페이지 | `GET /favorites/:id` | 개별 URL 상세 + AI 분석 결과 |
| S03 | 컬렉션 상세 | `GET /collections/:id` | 컬렉션 내 카드 목록 |
| S04 | 공유 수신 | `POST /share` | PWA share_target 수신 화면 |

**레이아웃 구성**
- 사이드바 (왼쪽 240px): 컬렉션 목록, 고정
- 메인 콘텐츠 (나머지): 입력바 + 필터 + 카드 그리드
- 카드 그리드: 2-3열 (화면 너비에 따라)
- 뷰 전환 버튼: 카드 / 리스트 (우측 상단)

## 라우트 매핑

| Method | Path | Controller#Action | 설명 |
|--------|------|-------------------|------|
| GET | `/` | `favorites#index` | 홈 화면 |
| GET | `/favorites` | `favorites#index` | 홈 화면 (alias) |
| POST | `/favorites` | `favorites#create` | URL 저장 |
| GET | `/favorites/:id` | `favorites#show` | 상세 페이지 |
| PATCH | `/favorites/:id` | `favorites#update` | 메모 업데이트 |
| DELETE | `/favorites/:id` | `favorites#destroy` | 삭제 |
| POST | `/favorites/:id/reanalyze` | `favorites#reanalyze` | 재분석 |
| GET | `/collections` | `collections#index` | 컬렉션 목록 (사이드바용) |
| POST | `/collections` | `collections#create` | 컬렉션 생성 |
| GET | `/collections/:id` | `collections#show` | 컬렉션 상세 |
| PATCH | `/collections/:id` | `collections#update` | 컬렉션 수정 |
| DELETE | `/collections/:id` | `collections#destroy` | 컬렉션 삭제 |
| POST | `/collection_memberships` | `collection_memberships#create` | 컬렉션에 추가 |
| DELETE | `/collection_memberships/:id` | `collection_memberships#destroy` | 컬렉션에서 제거 |
| POST | `/share` | `favorites#share` | PWA share_target |
| POST | `/favorite_notes/:id` | `favorite_notes#update` | 메모 저장 |

## 반응형 브레이크포인트

| 구간 | 화면 너비 | 레이아웃 |
|------|-----------|---------|
| 모바일 | < 768px | 1열, 사이드바 드로어, 바텀시트 필터 |
| 태블릿 | 768-1024px | 2열, 사이드바 숨김 또는 슬림 |
| 데스크탑 | > 1024px | 2-3열, 사이드바 고정 |
