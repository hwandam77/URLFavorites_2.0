# 01 — 제품 요구사항 문서 (PRD)

## 제품 본질

**urlf2** = "저장하면 AI가 검색 가능하게 만들어주는 개인 지식 아카이브"

URL을 붙여넣는 순간 AI가 콘텐츠를 분석하고, 태그/요약/핵심포인트를 자동 생성한다.
사용자는 나중에 "그 글 어디있더라"를 걱정하지 않아도 된다.

- 도메인: urlf2.hwandam.kr
- 사용자: 1인 (개발자 본인)
- 플랫폼: 웹 (PWA, 모바일 우선)

---

## 핵심 원칙 5가지

### 1. 저장은 1초
URL만 붙여넣으면 된다. 제목, 태그, 분류를 입력하지 않아도 저장 완료.
나머지는 AI가 처리한다.

### 2. AI가 자동 정리
저장 후 백그라운드에서 AI가 다음을 자동 생성한다:
- 요약 (3-5문장)
- 태그 (5-10개)
- 핵심포인트 (3-7개 bullet)
- YouTube의 경우 자막 기반 분석

### 3. 검색이 강력
FTS5 전문 검색 + AI 메타데이터 활용. 정확 일치 우선, 연관 결과 보조.
title, summary, tags, note 전체를 인덱스.

### 4. 메모는 선택적 강화 레이어
메모는 필수가 아니다. 정말 중요한 내용일 때만 추가하는 "강화 레이어".
저장의 마찰을 높이지 않는다.

### 5. 모바일 우선 저장
iOS/Android 공유 시트에서 앱처럼 저장 가능. PWA share_target 구현.
이동 중 발견한 콘텐츠도 즉시 아카이브.

## 기능 목록

### P0 — 핵심 (없으면 제품 불성립)

| 기능 | 설명 |
|------|------|
| URL 저장 | POST /favorites, 중복 방지, URL 정규화 |
| URL 안전성 검증 | 사설 IP 차단, HTTP/HTTPS만 허용 |
| 콘텐츠 타입 감지 | webpage vs youtube 자동 분류 |
| 웹페이지 스크래핑 | Nokogiri, 8000자 제한 |
| YouTube 추출 | yt-dlp, 자막 fallback, 12000자 제한 |
| AI 비동기 분석 | Solid Queue, 120s timeout, 자동 3회 재시도 |
| 상태 머신 | pending → analyzing → done/failed |
| FTS5 검색 | title/summary/tags/note 통합 검색 |
| 카드형 홈 | 통합 입력바 + 필터 칩 + 카드 목록 |
| 상세 페이지 | AI 요약/태그/핵심포인트/메모/재분석 |

### P1 — 중요 (초기 릴리즈에 포함)

| 기능 | 설명 |
|------|------|
| 컬렉션 CRUD | 북마크 그룹핑, 사이드바 네비게이션 |
| 필터 | 태그/컬렉션/콘텐츠타입/분석상태 |
| 카드/리스트 뷰 전환 | 보기 방식 선택 |
| Turbo Stream 실시간 갱신 | 분석 완료 시 카드 자동 업데이트 |
| PWA + 공유 시트 | 모바일 share_target |
| 모바일 반응형 | 1열 레이아웃, 바텀시트 필터 |

### P2 — 있으면 좋음 (후속 릴리즈)

| 기능 | 설명 |
|------|------|
| urlf 데이터 이관 | 기존 시스템 데이터 1회 임포트 |
| 오프라인 fallback | Service Worker 캐시 |
| 재분석 | 상세 페이지에서 AI 재실행 |
| 메모 편집 | 선택적 노트 추가/수정 |

- [ ] URL 저장 후 5초 내 카드가 홈에 표시됨 (pending 상태)
